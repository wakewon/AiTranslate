支持的主流请求格式

在插件设置中，根据你的 API 供应商选择对应的格式

选项名称 底层格式 适用服务商/模型
OpenAI Chat Completions（通用兼容） /v1/chat/completions 最通用的格式。适用于几乎所有兼容 OpenAI 的端点：DeepSeek, 硅基流动, OpenRouter, 智谱 GLM, 豆包, 阿里百炼, Ollama 等。
OpenAI Responses API /v1/responses OpenAI 新一代非对话标准，适合部分支持的较新模型。
OpenAI Legacy Completions /v1/completions 老旧模型或部分遗留系统的单轮对话格式。
Anthropic Claude Messages /v1/messages Claude 官方原生端点专用，支持 anthropic-version 等高级鉴权头。
Anthropic OpenAI 兼容 /v1/chat/completions 部分基于 Anthropic 但提供 OpenAI 兼容接口的服务。
Gemini generateContent /v1beta/models/{model}:generateContent Gemini 官方原生格式。注意：模型名会自动拼接到 URL 路径中。
Gemini OpenAI 兼容 /v1/chat/completions 部分基于 Gemini 但提供 OpenAI 兼容接口的服务。

快速安装与启用

  1. 在 GitHub Releases 下载最新的 .bobplugin 文件并双击安装。
  2. 在 Bob 的设置 -> 服务 -> 文本翻译中，点击左下角 + 号，添加 Ai 翻译。
  3. 根据您的服务商，在插件设置中选择对应的 请求格式（通常默认的 OpenAI Chat 就能通吃 90% 的服务商）。
  4. 填入您的 Base URL 和 API Key。注意：此插件的请求格式默认自带了版本和端点信息（如 /v1/chat/completions）。除非有特殊需求需要手动指定 Endpoint，一般 Base URL 填写根地址即可。
  5. 填入您要调用的 模型名称 (Model)。注意：这几乎是必填项，且必须填入服务商 API 文档中规定的具体模型参数名（例如 deepseek-v4-flash、glm-4-flash 等）。
  6. (可选) 您可以打开高级参数构建工具生成个性化参数（如关闭思考等）并粘贴到插件底部的“额外请求体”中。更多进阶玩法请访问文档中心阅读。
