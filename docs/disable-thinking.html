思考设置

能否关闭思考取决于模型和接口。例如，DeepSeek 官方 Chat Completions 支持思考开关，智谱 GLM-5.3 始终启用思考，最低强度为 low。

打开思考设置

应用到 Bob

在配置助手选择实际使用的服务、模型和请求格式。将对应的设置复制到 Bob「AiTranslate → 额外请求体 (JSON)」，保存后生效。若配置助手没有收录该模型的取值，可查服务商文档并手动填写。编辑请求参数

各接口的思考参数

DeepSeek

在官方 Chat Completions 接口中，deepseek-flash 和 deepseek-v4-pro 均可通过下列设置关闭思考。保留思考时，强度参数 reasoning_effort 可设为 low、high 或 max。DeepSeek 思考模式

{"thinking": {"type": "disabled"}}
OpenAI

Responses 和 Chat Completions 的参数位置不同。以下示例均设为 low。GPT-6 Luna 支持 none，GPT-6.2 Astra 和 Sol 会拒绝该值。OpenAI 推理指南 · GPT-6 Luna

Responses API

{"reasoning": {"effort": "low"}}

Chat Completions

{"reasoning_effort": "low"}
Claude · Messages

Haiku 5.5 用 thinking.type = disabled 关闭思考，强度须为 high 或更低。Sonnet 5.5 的 between_tools 仅关闭前置思考，工具调用间仍可推理，同样限于 high 或更低。Opus 5.5 和 Fable 5.2 始终使用自适应思考。Claude 各型号的思考模式

Google Gemini

选择「Gemini generateContent」和实际使用的模型。有官方档位记录的模型可在「思考设置」选择相应取值。例如，gemini-4-hydrogen 可以用 low 降低推理强度。

{"generationConfig": {"thinkingConfig": {"thinkingLevel": "low"}}}

部分 Gemini 3 Flash 型号提供 minimal，模型仍可能思考。Gemini 2.5 Flash-Lite 使用 thinkingBudget，设为 0 即可关闭思考。Google 思考参数说明 · 配置 Gemini 参数

通义千问（阿里云百炼）

通过百炼的 OpenAI 兼容 Chat Completions 使用支持此开关的混合思考模型时，可将 enable_thinking 设为 false。百炼深度思考说明

{"enable_thinking": false}
智谱 GLM

GLM-5.3 及其 Flash、FlashX 型号始终启用思考，可将强度设为 low、high 或 max。GLM-5.2 支持以 thinking.type = disabled 关闭思考。智谱思考模式 · Flash 与 FlashX 说明

{"reasoning_effort": "low"}
OpenRouter

以 OpenRouter 上的完整模型 ID 为准。模型目录中的 reasoning.supported_efforts 列出可选强度，mandatory 为 true 表示模型始终推理。实际聊天请求使用 reasoning.effort。OpenRouter 思考参数

本地 Ollama

使用 OpenAI 兼容接口时，先从本地服务的 /api/show 查看模型支持的推理档位。兼容接口可用 reasoning_effort，none 的实际效果取决于模型，例如 GPT-OSS 会按最低档位运行。Ollama 兼容接口

模型或自定义端点的思考选项尚未收录时，可把当前设置和插件文档一起交给能联网的 AI 助手核对。生成思考设置查询提示词

验证与还原

保存后用同一段原文比较响应时间和译文。移除新增字段并保存，即可恢复原先的思考设置。

核对推理用量

有些服务会在控制台记录每次请求的思考用量。找到本次翻译，对比调整前后的推理 Token 数。如果返回 400 错误，核对报错中提到的参数名和可用取值。

SDK 示例中的 extra_body

有些 SDK 把自定义字段放在 extra_body 中。Bob 的「额外请求体 (JSON)」只需要里面的字段。如果已经设置了其他参数，把它们合并在同一对花括号内。编辑额外请求参数
