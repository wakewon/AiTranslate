调整推理参数

有些模型会先推理再给出译文。翻译短句时，如果等待时间比较长，可以降低推理强度。支持关闭推理的模型也可以直接输出译文。

把参数填在哪里

在 Bob 的「Ai 翻译」服务设置中找到「额外请求体 (JSON)」，填入当前接口接受的 JSON 对象。已有其他参数时，将新字段加进同一对花括号内。

有些 SDK 把自定义字段放在 extra_body 中。插件直接发送 HTTP 请求，复制到 Bob 时只需保留里面的字段。在工作台编辑 JSON

按接口查参数

先认准实际调用的平台，再核对模型支持的档位。同一款模型经第三方平台调用时，以该平台的接口说明为准。

DeepSeek 官方 Chat Completions

使用支持思考开关的模型时，将 thinking.type 设为 disabled。DeepSeek 思考模式

{"thinking": {"type": "disabled"}}
OpenAI Responses 与 Chat Completions

同一个模型换用这两个接口时，参数所在的位置会变。例如，要使用 low 档位，先确认模型支持该值，再选择对应的写法。支持 none 的模型可以把值改为 none。OpenAI 推理指南

Responses API

{"reasoning": {"effort": "low"}}

Chat Completions

{"reasoning_effort": "low"}
Google Gemini · generateContent

选择「Gemini generateContent」和实际使用的模型。如果「JSON 参数」显示「当前模型的思考等级」，选中需要的档位，再把生成的 JSON 复制到 Bob 的「额外请求体」。例如，gemini-4-hydrogen 可以用 low 降低推理强度。

{"generationConfig": {"thinkingConfig": {"thinkingLevel": "low"}}}

Gemini 2.5 系列用 thinkingBudget 控制推理预算，允许的范围因型号而异。Google 思考参数说明 · 配置 Gemini 参数

通义千问 · 阿里云百炼

通过百炼的 OpenAI 兼容 Chat Completions 使用支持此开关的混合思考模型时，可将 enable_thinking 设为 false。百炼深度思考说明

{"enable_thinking": false}
智谱 · GLM-5.3

GLM-5.3 始终启用思考。要减少推理量，可以选择其最低档位 low。GLM-5.3 参数说明

{"thinking": {"type": "enabled"}, "reasoning_effort": "low"}
Ollama · OpenAI 兼容接口

先从本地服务的 /api/show 查看模型支持的推理档位。兼容接口可用 reasoning_effort，none 的实际效果取决于模型，例如 GPT-OSS 会按最低档位运行。Ollama 兼容接口

使用其他服务时，可在工作台填写服务商和模型名称，生成一段供 AI 助手查官方资料的提问。生成推理参数查询提示词

验证参数是否生效

  1. 先将「额外请求体」留空，翻译一句短文本，确认当前地址和模型能正常返回译文。
  2. 只加入准备测试的参数并保存，再译同一句话。遇到 400 错误时，查看返回信息提到的字段名和允许值。
  3. 如果 Bob 能显示译文，但你不确定模型是否仍在推理，可到服务商控制台查看这次请求的用量。服务商如提供推理 Token 数，可用它核对变化。清空新增字段即可恢复模型默认行为。
