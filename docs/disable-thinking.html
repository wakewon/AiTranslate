进阶：如何为模型“关闭思考”？

通过自定义额外参数，强制让满血版的推理模型直接输出结果

1. 什么是请求头和请求体？

AiTranslate 插件支持在 Bob 配置界面的高级设置中注入 额外请求头 (Headers)、额外查询参数 (Query) 和 额外请求体 (Body)。它们都接收合法的 JSON 格式字符串。

对于关闭深度思考（思维链）这种操作，几乎都是通过修改“请求体 (Body)”来实现的，因为这属于修改发给模型的具体指令参数。

你可以使用我们提供的 参数构建工具，快速生成所需的 JSON 字符串，然后复制粘贴到 Bob 的「额外请求体」输入框中即可。

2. 各大平台关闭思考的 JSON 模板

适用服务商 / 模型 所需的 JSON 结构（填入额外请求体） 说明
DeepSeek 官方 API / 智谱 GLM / 豆包 / 腾讯 { "thinking": { "type": "disabled" } } DeepSeek 官方 API 及多数国产大厂通用。
OpenAI (gpt-5.5 / o1 / o3 等) { "reasoning_effort": "none" } 标准 OpenAI 兼容参数。值可以设为 "none", "low", "medium", "high" 来调节思考深度。
通义千问 / 阿里云百炼 { "enable_thinking": false } 直接使用布尔值开关。
Ollama (本地部署) { "think": false } 针对部分支持 Ollama 的推理模型控制。

3. 通过 AI 助手获取配置方案

如果您使用了一个尚未列出的全新推理模型（或者服务商的 API 发生了更新），不确定该如何关闭深度思考，您可以直接将以下提示词发送给 AI（如 ChatGPT / Claude），让它查阅最新的官方文档并为您提供准确的配置参数：

我正在配置一款名为 AiTranslate 的翻译插件（https://wakewon.github.io/AiTranslate/）。

我现在接入了【在此填入服务商和模型名称，例如：硅基流动的 DeepSeek-R1】。
该插件允许向大模型服务端注入自定义的 JSON 请求体（Extra Body）来控制高级参数。请查阅其最新的官方 API 文档，告诉我如果要强制关闭或最小化该模型的“深度思考/思维链（Reasoning）”功能以加快响应速度，我应该在发出的 JSON 请求体中添加什么参数？

请注意：不要泛泛而谈，请直接给出一个准确的 JSON 对象代码示例。例如，如果该模型兼容 OpenAI 的 reasoning_effort，你应当输出：
```json
{
  "reasoning_effort": "none"
}
```

同时，请附上你参考的官方文档链接以供核查。
