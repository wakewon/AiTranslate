使用指南

从安装插件开始，让 Bob 译出第一句话。已经能看到译文的话，可以直接查找想改的设置。

第一次使用

用 bilibili 翻译试一次，可以跳过申请密钥这一步。已经有 DeepSeek 等服务的密钥，或者 Mac 上已装好本地模型，也能按同一篇指南设置。

跟着做第一次翻译

我已经装好了

换一个翻译服务 找到你要用的平台，查看 Bob 里对应的填法。 希望译文保留术语和排版 把常用的翻译要求保存到 Bob，下次翻译时自动带上。 翻译短句时想少等一会儿 看看你的模型能否少花一些时间思考。 验证失败或没有译文 按 Bob 显示的提示，找到对应的处理方法。
