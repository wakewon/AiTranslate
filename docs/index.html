使用指南

用已有的云端服务或本地模型完成第一次翻译，再按需要调整译文格式和推理强度。

在 Bob 中使用

安装插件，完成第一次翻译 添加文本翻译服务，填写地址、模型和密钥，用一句短文本验证配置。 编写翻译指令 保留原文的段落、术语和代码，让模型按你的习惯给出译文。 调整推理参数 核对模型能否关闭思考、支持哪些档位，以及怎样填写额外请求体。

查找配置

服务商目录
查接口地址、请求格式和鉴权方式，从服务商条目进入对应的配置。
配置工作台
选择服务商或填写自建端点，准备要复制到 Bob 的字段和提示词。
常见问题
检查验证失败、流式响应为空，以及 Markdown 译文的显示方式。
