第一次翻译

先在 Bob 里添加「Ai 翻译」，再接入你已有的模型。第一次只需填好地址、模型和鉴权信息，提示词和额外参数都可以留空。

安装并添加服务

  1. 打开最新版的发布页，在 Assets 下下载后缀为 .bobplugin 的安装包，双击安装。插件需要 Bob 1.8.0 或更高版本。下载插件
  2. 在 Bob 的「偏好设置 → 翻译 → 服务」中选中「文本翻译」，点击列表下方的加号，选择「Ai 翻译」。
  3. 在服务商目录选中你的服务，进入配置工作台，把对应的请求格式、地址和模型 ID 填回 Bob。如果服务需要密钥，将它填入 Bob 的「API Key」。查询服务商
  4. 点击「验证」。插件会发送一次非流式请求，将 hello 译成简体中文。验证通过后，开启服务并点击「保存」，就可以在 Bob 中划词翻译了。Bob 添加服务说明

填写地址和请求格式

在服务商文档里找到发送请求的网址。以 OpenAI 的 https://api.openai.com/v1/chat/completions 为例，「Base URL」填 https://api.openai.com，选择 Chat Completions 后，插件会补上后半段路径。

如果服务商用的路径不同，在「端点路径覆盖」中填写从 / 开始的完整路径。插件会将它直接接在 Base URL 后面。把 /v1 同时写进这两个字段会导致地址重复。

其他兼容服务怎么填？

Together AI 的 Chat Completions 可以使用默认格式，Base URL 填 https://api.together.ai。模型名称通常包含提供方前缀，要从 Together 当前的模型列表完整复制。Together AI 接口说明

使用 DeepSeek 的 Anthropic 兼容接口时，选择「Anthropic Claude Messages」，Base URL 填 https://api.deepseek.com，端点路径覆盖填 /anthropic/v1/messages。DeepSeek 的 Anthropic 接口

使用 vLLM、llama.cpp 或 LocalAI 自建服务时，先确认服务器提供的接口和模型 ID。在工作台的「自定义服务商」中填入实际地址，就可以生成配置查询提示词。查询自定义配置

Gemini 原生接口

选择「Gemini generateContent」，Base URL 填 https://generativelanguage.googleapis.com，「端点路径覆盖」留空。在「模型」里填写模型 ID，省略 models/ 前缀。插件会构造 /v1beta/models/{model}:generateContent，开启流式时自动改用 :streamGenerateContent?alt=sse。

如果代理要求你手填路径，请把 {model} 换成实际 ID，并选择与流式开关对应的接口。插件会原样发送这条路径。Gemini 接口文档

找到正确的模型 ID

到实际提供 API 的平台查 ID，再把它完整复制到「模型」。同一个模型在不同平台可能有不同的名称。

云端 API
在服务商控制台确认该模型支持文本生成，且已向你的账号、项目和地区开放。从目录查官方文档
Azure OpenAI
填资源中自定义的部署名称。可以在部署详情中复制。Microsoft 部署说明
本地服务
Ollama 填 ollama list 列出的名称，保留冒号后的标签。LM Studio、vLLM 等服务填当前服务器提供的模型 ID。LM Studio 模型列表

选择鉴权方式

通常保留「自动（按请求格式）」，在「API Key」里粘贴原始密钥。插件对 Gemini 原生接口使用 x-goog-api-key，对其他六种格式添加 Authorization: Bearer 请求头。

服务商指定了其他请求头或 URL 参数

按接口要求，在「鉴权方式」里选择 x-api-key、x-goog-api-key、api-key 或 URL 查询参数 key。例如，Azure 用资源密钥时选 api-key，用 Microsoft Entra 访问令牌时选 Bearer。Azure 鉴权说明

使用 Claude 的跨工作区密钥时，在「额外请求头」填写目标工作区的 anthropic-workspace-id。Claude 鉴权说明

本地 Ollama 或 LM Studio 需要填密钥吗？

直连默认的本地 Ollama 或 LM Studio 时，「API Key」留空即可。LM Studio 开启鉴权后要填服务器签发的令牌。经代理访问时要看代理的设置，直连 Ollama Cloud 则要填云端密钥。Ollama 鉴权 · LM Studio 鉴权

已经在额外字段里配置了凭据

自动模式遇到已有的标准鉴权头或查询参数 key 时，会沿用你提供的值。若服务用自定义名称，可选「手动或无需鉴权」，再填写额外请求头或额外查询参数。请求头名称不区分大小写。留空「API Key」也会跳过自动鉴权。

让译文保留原文格式

插件已有默认翻译指令。需要保留术语、代码或 Markdown 结构时，可以把固定要求写在「自定义系统指令」里。下面是一组翻译技术文档的示例。

自定义系统指令

你是技术文档译者。保留代码、变量名和 Markdown 结构，只输出译文。

自定义用户指令

请将下面的 $sourceLang 原文译成 $targetLang。

$text

插件会把 $text 换成选中的原文，把两个语言变量换成 Bob 提供的语言名称。自行填写用户指令时记得保留 $text。在工作台生成翻译指令

排查常见问题

提示 401 或 403

检查密钥是否属于当前 Base URL 对应的平台，是否有权访问该模型。选择 Bearer 时只填令牌本身，插件会添加前缀。

提示 404 或找不到模型

将 Base URL 与端点路径拼在一起，与服务商文档逐段比较。再查模型 ID 的拼写、地区和部署名称。

验证通过，翻译时提示「流式响应为空」

「验证」使用非流式请求。先关闭「流式输出」再翻译同一句话。如果这样能收到译文，请核对端点的流式接口和代理的 SSE 支持。

译文里能看到 Markdown 标记

Bob 1.21.0 及以上搭配 macOS 13 及以上可以渲染 Markdown。检查插件里的「Markdown 渲染」和 Bob 的「偏好设置 → 翻译 → Markdown」。较早的版本会按纯文本显示。需要纯文本译文时，也可以在系统指令中指定。Bob 的 Markdown 支持说明
