基础使用教程

从零开始，教你如何接入任意 AI 翻译服务

快速安装与启用

  1. 在 GitHub Releases 下载最新的 .bobplugin 文件并双击安装。
  2. 在 Bob 的设置 -> 服务 -> 文本翻译中，点击左下角 + 号，添加 Ai 翻译。
  3. 根据您的服务商，在插件设置中选择对应的 请求格式（通常默认的 OpenAI Chat 就能通吃 90% 的服务商）。
  4. 填入您的 Base URL 和 API Key。注意：此插件的请求格式默认自带了版本和端点信息（如 /v1/chat/completions）。除非有特殊需求需要手动指定 Endpoint，一般 Base URL 填写根地址即可。
  5. 填入您要调用的 模型名称 (Model)。注意：这几乎是必填项，且必须填入服务商 API 文档中规定的具体模型参数名（例如 deepseek-v4-flash、glm-4-flash 等）。
  6. (可选) 您可以打开高级参数构建工具生成个性化参数（如关闭思考等）并粘贴到插件底部的“额外请求体”中。更多进阶玩法请访问文档中心阅读。

1. 请求格式怎么选？

本插件支持 7 种细分的 API 请求格式选项，它们决定了插件如何与大模型通信：

  • OpenAI Chat Completions（通用兼容）: 最通用的格式，绝大多数国产模型（DeepSeek、Kimi、豆包、智谱等）和第三方中转站（硅基流动、OpenRouter）都兼容此格式。
  • OpenAI Responses API: OpenAI 新一代的非对话文本生成端点（如 o1 等部分模型适用）。
  • OpenAI Legacy Completions: 老旧模型或部分遗留系统的单轮对话格式。
  • Anthropic Claude Messages: Claude 官方原生端点专用。
  • Anthropic OpenAI 兼容: 部分基于 Anthropic 但提供 OpenAI 兼容接口的服务。
  • Gemini generateContent: 谷歌 Gemini 官方原生端点专用。
  • Gemini OpenAI 兼容: 部分基于 Gemini 但提供 OpenAI 兼容接口的服务。

2. Base URL 和端点（Endpoint）填写指南

Base URL (基础网址) 是服务商的根地址。端点 (Endpoint) 则是具体的接口路径。根据不同的 API 格式，插件会自动拼接路径，但有时你需要自己手动调整端点：

案例 A：DeepSeek 官方 API

参考文档：DeepSeek 官方文档

  • 请求格式： OpenAI Chat Completions
  • Base URL： https://api.deepseek.com （不要带 /v1）
  • 自定义端点： 留空 （插件默认使用的请求格式会自动补充 /v1/chat/completions）

案例 B：Google Gemini 官方 API（非标准路径）

参考文档：Gemini 官方文档

  • 请求格式： Gemini 官方 generateContent
  • Base URL： https://generativelanguage.googleapis.com
  • 自定义端点： /v1beta/models/{model}:generateContent （注意保留大括号里的 {model}，插件会自动将其替换为你在下方填写的模型名称）

案例 C：智谱 GLM 官方 API（特殊后缀）

如果你遇到类似于智谱这样不规则的 API 路径：智谱官方文档

  • 请求格式： OpenAI Chat Completions
  • Base URL： https://open.bigmodel.cn
  • 自定义端点： /api/paas/v4/chat/completions（填写后，插件将不再自动补充路径，而是完全使用你填写的端点）
